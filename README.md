# improved-octo-fishstick

Repository initialized by GitHub Copilot assistant.

This repository contains both Node and Python minimal scaffolds and CI.

Quick commands:

- Install Node dependencies:

```bash
npm ci
```

- Run Node tests:

```bash
npm test
```

- Run Python tests:

```bash
python -m unittest discover -v
```

- Serve the page locally with Python:

```bash
python serve.py
```

- Or serve the page with npm:

```bash
npm start
```

Then open `http://127.0.0.1:8000` in your browser.
